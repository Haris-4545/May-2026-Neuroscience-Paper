# May-2026-Neuroscience-Paper
"Neural Mechanisms of Reinforcement Learning: Developmental Variance in Reward Prediction Error Signalling and Adolescent Risk-Taking". The Question this paper seeks to answer is "to what extent age-related differences in ventral striatal reward prediction error signals explain elevated risk-taking behaviour in adolescents compared to adults?"
This is a Python script that was used to conduct an analysis and create graphs for the paper.
